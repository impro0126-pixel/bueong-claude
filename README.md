# 가계부엉 × 클로드

[가계부엉](https://apps.apple.com/app/id6811481053)의 「클로드 연동」을 쓰기 위한 연결 도구입니다.

카드·통장 캡처를 클로드에 올리면, 클로드가 거래를 읽어 분류한 뒤 가계부엉의 **받은편지함**에 넣어 둡니다. 앱에서 받은편지함을 열고 고른 것만 반영하면 끝이에요.

## 준비물

- 맥
- [클로드 데스크톱 앱](https://claude.ai/download) — 무료 요금제에서도 돼요.
- 가계부엉 맥 앱 — 맥에서 **한 번 실행**하고 설정 → 「클로드 연동」을 켜 주세요.
- **iCloud Drive 켜기 (필수)** — 시스템 설정 → Apple 계정 → iCloud 에서 켤 수 있어요. 꺼져 있으면 맥이 클로드가 가계부엉 자료를 읽지 못하게 막아요.

아이폰만으로는 연결할 수 없어요. 클로드가 맥에서 가계부엉 폴더에 파일을 놓는 방식이라 맥이 필요합니다. 맥에서 넣은 거래는 iCloud 로 아이폰에도 보여요.

## 설치

1. **[가계부엉.mcpb 받기](https://github.com/impro0126-pixel/bueong-claude/releases/latest/download/bueong.mcpb)**
2. 받은 파일을 더블클릭하세요. 클로드 앱이 열리며 설치 화면이 떠요.
3. **설치**를 누르세요.

더블클릭으로 안 열리면 클로드 앱 → 설정 → 확장 프로그램 화면에 파일을 끌어다 놓으세요.

설치 화면에 빨간 경고(「컴퓨터의 모든 항목에 액세스할 수 있는 권한」, 「Anthropic에서 확인하지 않았습니다」)가 떠요. 앱스토어처럼 심사를 거치지 않고 직접 나눠 주는 확장이면 늘 뜨는 문구예요. 이 도구가 실제로 읽고 쓰는 것은 아래 「내 자료는 어디로 가나요」에 적어 두었어요.

## 쓰기

1. 클로드 앱의 **채팅**(왼쪽 위 말풍선)에서 새 대화를 열고, 카드·통장 캡처를 올리며 「가계부에 넣어줘」라고 하세요. 클로드 코드(Code) 화면에서는 이 확장이 붙지 않아요.
2. 클로드가 가계부엉에 등록된 카드·통장·분류 이름을 읽어 와서 그 이름으로 분류해요. 처음 한 번은 주로 쓰는 카드가 무엇인지 물어봐요.
3. 가계부엉에서 받은편지함을 열고 확인한 뒤 반영하세요.
   - 맥: 쓰기 화면 위 **⊕(추가) 메뉴 → 받은편지함**
   - 아이폰: 쓰기 화면 왼쪽 위 받은편지함 단추

통장 캡처를 넣으면 클로드가 통장 잔액도 같이 보내서, 받은편지함 위쪽에 「통장 잔액과 일치합니다」가 뜨는지로 빠진 거래나 겹친 거래가 없는지 확인할 수 있어요.

「이번 달 식비 얼마 썼지」처럼 물어도 돼요. 클로드가 가계부엉의 거래를 읽어 답해요.

무엇을 시킬지 모르겠으면 채팅 입력창의 **＋ → 커넥터 → 가계부엉에서 추가**에서 골라 보세요. 「캡처 처리하기」, 「이번 달 지출 보기」, 「처음 설정하기」가 있어요. 같은 커넥터 목록에서 「가계부엉」 스위치가 켜져 있어야 클로드가 도구를 써요.

### 아이폰에서 찍어 맥의 클로드에게 보내기

1. 아이폰 가계부엉 → 설정 → 「캡처 넣는 방법」을 **맥의 클로드에 보내기**로 고르세요.
2. 쓰기 화면에서 캡처를 골라 보내요. 한 줄 메모(「이건 회식비야」)를 같이 남길 수 있어요.
3. 맥의 클로드 채팅에서 「캡처 처리해줘」라고 하세요. 클로드가 캡처를 읽어 받은편지함에 넣고, 넣은 캡처는 폰 화면에 「맥에서 처리했어요」로 바뀌어요.

캡처는 iCloud Drive 로 맥에 건너가요. 아이폰과 맥 둘 다 iCloud Drive 가 켜져 있어야 해요. 맥이 없으면 기본값인 「이 기기에서 글자 읽기」를 쓰세요 — 아이폰 안에서 날짜·상호·금액을 읽어 줘요.

## 내 자료는 어디로 가나요

- 이 도구는 맥 안에서만 돌아요. 저희 서버가 없고, 가계부 자료는 인터넷으로 보내지 않아요.
- 인터넷으로 나가는 것은 **하나**예요. 하루 한 번 깃허브에서 이 도구의 **새 판 번호만** 확인해요. 새 판이 있으면 클로드가 「새 판이 있어요」라고 알려 줘요. 끄려면 클로드 앱 → 설정 → 확장 프로그램 → 「가계부엉」 → **「새 판 확인」을 끄세요.** 손으로 설치했다면 `BUEONG_UPDATE_CHECK=off` 환경변수로 꺼요.
- 클로드가 **쓰는** 곳은 두 군데예요.
  - iCloud Drive 의 가계부엉 폴더에 있는 받은편지함(`inbox.json`) — 가계부에 넣을지는 앱에서 직접 고르세요.
  - 클로드가 기억해 둔 주력 카드와 가맹점 분류 규칙 — 맥의 `Library/Application Support/kakeibo-mcp/` 폴더예요.
  - 처리를 마친 아이폰 캡처는 같은 폴더의 `captures/처리됨/` 으로 옮겨요(지우지 않아요).
- 클로드가 **읽는** 것은 등록된 카드·통장·분류의 **이름**, 물어본 기간의 **거래 내역**, 그리고 아이폰에서 보낸 **캡처**예요. 읽은 내용은 그 클로드 대화에 올라가요(캡처를 올리는 것과 같아요). 통장 잔액·투자 원금·연말정산 설정은 읽지 않아요.
- 읽기를 원치 않으면 맥 가계부엉에서 「클로드 연동」을 끄세요. 클로드가 읽던 사본이 지워져요.

## 잘 안 될 때

- **받은편지함이 비어 있거나, 클로드가 「사본이 없다」고 해요** → 맥에서 가계부엉을 켜고 설정 → 「클로드 연동」이 켜져 있는지 보세요. 켠 뒤 앱을 한 번 열어 두면 돼요.
- **클로드가 「폴더 접근을 막았다」고 해요** → iCloud Drive 가 꺼져 있는 맥이에요. iCloud Drive 를 켜고 가계부엉을 껐다 켜세요.
- **클로드가 도구를 못 찾아요** → 클로드 앱 → 설정 → 확장 프로그램에 「가계부엉」이 켜져 있는지 보고, 클로드 앱을 완전히 껐다 켜세요. 채팅이 아니라 클로드 코드 화면에서 물었다면 채팅에서 다시 물어보세요.

## 새 판으로 바꾸기·지우기

- **새 판으로 바꾸기**: 클로드가 「새 판이 있어요」라고 하면 바꿀 때예요. 위 「가계부엉.mcpb 받기」로 새 파일을 받아 다시 더블클릭해 설치한 뒤, **클로드 앱을 완전히 껐다 켜세요(⌘Q)**. 껐다 켜기 전에는 채팅이 옛 판의 기능만 알아요. 설치가 안 되면 아래처럼 지운 뒤 새로 설치하세요. 어느 쪽이든 클로드가 기억한 카드·가맹점 규칙은 확장과 따로 저장돼 있어 그대로 남아요.
- **지우기**: 클로드 앱 → 설정 → 확장 프로그램 → 「가계부엉」 → 제거.

## 클로드 코드로 쓰거나 손으로 설치하려면

의존성이 없는 파일 하나(`bueong-mcp.js`)라서 Node.js 18 이상만 있으면 돼요.

```bash
git clone https://github.com/impro0126-pixel/bueong-claude.git "$HOME/bueong-claude"
```

```bash
claude mcp add bueong -- node "$HOME/bueong-claude/bueong-mcp.js"
```

클로드 데스크톱에 손으로 넣으려면 설정 → 개발자 → 설정 편집에서 `claude_desktop_config.json` 에 아래를 더하세요(`이름` 은 맥 사용자 이름). 위 확장을 이미 설치했다면 같은 도구가 두 벌 뜨니 둘 중 하나만 쓰세요.

```json
{
  "mcpServers": {
    "bueong": {
      "command": "node",
      "args": ["/Users/이름/bueong-claude/bueong-mcp.js"]
    }
  }
}
```

클로드 코드를 쓰신다면 이 저장소의 [`CLAUDE.md`](CLAUDE.md)를 가계부 작업 폴더에 두면 분류 규칙을 더 잘 지켜요. 도구는 iCloud Drive 의 가계부엉 폴더를 먼저 보고, 없으면 앱 자기 폴더(`~/Library/Containers/com.bueong.app/Data/Documents`)를 봐요. 다른 자리를 쓰려면 `BUEONG_DIR` 환경변수로 알려 주세요.

## 도구

| 도구 | 하는 일 |
|---|---|
| `get_names` | 가계부엉에 등록된 통장·카드·분류 이름 읽기 |
| `get_transactions` | 가계부엉의 거래를 기간으로 읽기 |
| `get_captures` | 아이폰에서 보낸 캡처를 그림으로 가져오기 (한 번에 3장) |
| `finish_captures` | 거래를 다 넣은 캡처를 처리됨으로 옮기기 |
| `get_config` | 클로드가 기억하는 주력 카드·가맹점 규칙 읽기 |
| `set_config` | 그 기억 저장 (맥의 `Library/Application Support/kakeibo-mcp/`) |
| `add_transactions` | 거래·잔액·카드 합계를 받은편지함에 넣기 |
