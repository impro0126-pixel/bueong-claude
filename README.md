# 가계부엉 × 클로드

[가계부엉](https://apps.apple.com/app/id6811481053)의 「클로드 연동」을 쓰기 위한 연결 도구(MCP 서버)입니다.

카드·통장 캡처를 클로드에 올리면, 클로드가 거래를 읽어 분류한 뒤 가계부엉의 **받은편지함**에 넣어 둡니다. 앱에서 받은편지함을 열고 고른 것만 반영하면 끝이에요.

- 클로드가 쓰는 곳은 아이클라우드 드라이브의 가계부엉 폴더(`inbox.json`) 하나뿐이에요.
- 가계부 자료를 외부 서버로 보내지 않아요. 이 도구는 맥 안에서만 돌아요.
- 의존성이 없는 파일 하나(`bueong-mcp.js`)예요.

## 준비물

- 맥 (클로드 데스크톱 앱 또는 클로드 코드)
- [Node.js](https://nodejs.org) 18 이상 — 터미널에서 `node -v` 로 확인
- 가계부엉 맥 앱 — 맥에서 **한 번 실행**하고 설정 → 「클로드 연동」을 켜 주세요. 이때 아이클라우드 폴더가 생겨요.

## 설치

### 1. 파일 받기

```bash
git clone https://github.com/impro0126-pixel/bueong-claude.git ~/bueong-claude
```

git 이 없으면 이 페이지 위쪽 **Code → Download ZIP** 으로 받아 홈 폴더에 `bueong-claude` 로 풀어 두세요.

### 2-1. 클로드 데스크톱 앱에 연결

클로드 앱 → 설정 → 개발자 → **설정 편집**을 누르면 `claude_desktop_config.json` 이 열려요. 아래를 넣고 저장하세요. (`이름` 은 맥 사용자 이름으로 바꿔 주세요. 터미널에서 `echo $HOME` 으로 확인)

```json
{
  "mcpServers": {
    "kakeibo": {
      "command": "node",
      "args": ["/Users/이름/bueong-claude/bueong-mcp.js"]
    }
  }
}
```

이미 다른 `mcpServers` 가 있으면 그 안에 `"kakeibo": { ... }` 만 더하면 돼요. 저장한 뒤 **클로드 앱을 완전히 껐다 켜세요.**

### 2-2. 클로드 코드에 연결

```bash
claude mcp add kakeibo -- node ~/bueong-claude/bueong-mcp.js
```

## 쓰기

1. 클로드에 카드·통장 캡처를 올리고 「가계부에 넣어줘」라고 하세요.
2. 처음 한 번은 쓰는 카드와 통장 이름을 물어봐요. **가계부엉에 등록한 이름 그대로** 알려 주세요.
3. 가계부엉 → 쓰기 화면 왼쪽 위 받은편지함에서 확인하고 반영하세요.

통장 캡처를 넣으면 클로드가 통장 잔액도 같이 보내서, 받은편지함 위쪽에서 「통장 잔액과 일치합니다」로 빠진 거래나 겹친 거래가 없는지 확인할 수 있어요.

클로드 코드를 쓰신다면 이 저장소의 [`CLAUDE.md`](CLAUDE.md)를 가계부 작업 폴더에 두면 분류 규칙을 더 잘 지켜요.

## 잘 안 될 때

- **받은편지함이 비어 있어요** → 맥에서 가계부엉을 한 번 켜고 「클로드 연동」이 켜져 있는지 보세요. 아이클라우드 폴더는 앱이 만들어요.
- **클로드가 도구를 못 찾아요** → 설정 파일의 경로가 맞는지, 클로드 앱을 완전히 껐다 켰는지 확인하세요.
- **폴더 자리를 바꾸고 싶어요** → 설정에 `"env": { "BUEONG_DIR": "폴더 경로" }` 를 더하세요. 비워 두면 `~/Library/Mobile Documents/iCloud~com~bueong~app/Documents` 를 써요.

## 도구

| 도구 | 하는 일 |
|---|---|
| `get_config` | 클로드가 기억하는 카드·통장·가맹점 규칙 읽기 |
| `set_config` | 그 기억 저장 (`~/Library/Application Support/kakeibo-mcp/`) |
| `add_transactions` | 거래·잔액·카드 합계를 받은편지함에 넣기 |
